# Superseded categorisation migration prompt

This historical prompt was used to create the earlier five-family,
two-level taxonomy. It is superseded by taxonomy 4.0 and must not be used to
update the catalogue.

The current sources are:

- `fdca-categories.json` for families, primary categories, bilingual names and
  short descriptions;
- `fdca-classification-rules.json` for the executable decision sequence; and
- `company-category-classification-rules.md` for the generated human-readable
  guide.

The registry now stores one primary category. Family membership is derived,
and family colours belong to `DESIGN.md`.
